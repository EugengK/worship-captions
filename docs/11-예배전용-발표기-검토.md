# 예배 전용 발표기(PPT만) 검토 — 옛 MacBook Air에서도 돌릴 수 있나 (2026-10-28)

> 표기: **[확인]** 코드·자료로 확인 / **[의견]** Claude의 판단 / **[검증 필요]** 시험해야 앎

## 1. 질문
이음오피스에서 워드·엑셀 등은 필요 없고 PPT만 쓴다. 기능을 줄여 가볍게 만들면 **교회 MacBook Air(2013~14, Big Sur)**에서도 쓸 수 있지 않을까?

## 2. 답: "기능을 줄이는 것"만으로는 안 되고, "PPT 부품만 떼어 웹으로 만드는 것"은 됩니다
### 2-1. 걸림돌은 성능이 아니라 운영체제 버전
- 이음오피스는 Electron 43 위에서 돌고, **Electron 38부터 macOS 11(Big Sur)을 지원하지 않습니다** [확인: docs/10].
- 워드·엑셀을 빼도 Electron은 그대로이므로 **요구 macOS 버전은 낮아지지 않습니다.**

### 2-2. 대신, PPT 부품만 떼어 "웹페이지 발표기"로 만들 수 있습니다
코드를 확인한 결과 [확인]:
| 부품 | 상태 |
|---|---|
| `packages/pptx-engine` (pptx 읽기) | 브라우저용 라이브러리(jszip, fast-xml-parser) 기반. Node 전용 코드는 **3곳뿐**(`randomUUID`, `createHash`, `deflateSync`)이고, 브라우저 기능으로 쉽게 바꿀 수 있음 |
| `packages/pptx-render` (슬라이드 그리기) | 순수 계산 코드, Node·Electron 의존 없음 |
| 발표 화면 부품 (`AudienceView`, `AnimatedSlide`, `ShowMediaLayer` 등) | Electron을 직접 쓰지 않음. 앱 본체와는 **약 10개의 호출**로만 연결 → 웹용으로 바꿔 끼울 수 있음 |
| 라이선스 | Apache-2.0 → 떼어 써도 됨 (출처·라이선스 표기 필요) |

→ **Electron 없이 브라우저에서 도는 "예배 전용 발표기"**를 만들 수 있다고 봅니다 [의견].
- 옛 맥에서 쓸 수 있는 브라우저: **Chrome 138**(Big Sur 마지막 버전), **Safari 16.6** [확인: [MacTrast](https://www.mactrast.com/2025/07/google-chromes-support-for-macos-big-sur-ends-with-version-138/), [Macworld](https://www.macworld.com/article/2850293/google-chrome-ends-support-for-macos-big-sur.html)].
  - 둘 다 보안 업데이트가 끝난 브라우저입니다. 다만 발표기는 **내 맥의 pptx 파일과 내 맥의 자막 허브(localhost)에만** 접속하므로 위험은 작다고 봅니다 [의견].

## 3. 두 길 비교
| | 이음오피스 패치 (현재, `ieumoffice/`) | **예배 전용 웹 발표기 (새 안)** |
|---|---|---|
| 옛 MacBook Air | ✕ (macOS 12 필요) | **○** (Chrome 138 / Safari 16.6) |
| 설치 | Node + Rust + 빌드 필요 | **웹페이지 파일 + 자막 허브만** |
| 개발량 | 거의 끝남 (3곳 수정) | 더 큼: pptx 열기, 발표자 화면, 프로젝터 화면 동기화, 영상·애니메이션 연결 |
| 원본 업데이트 추적 | 패치 재적용 | 필요한 부품만 가져왔으므로 덜 자주 |
| 예배 맞춤 기능 | 어려움 | 쉬움: 자막 띠 내장, 매주 찬양·성경 구절 자동 교체, 큰 글씨 발표자 화면 등 |
| 성능 (옛 맥) | – | 정지 슬라이드는 문제없을 것으로 예상, **전환 효과·영상은 시험 필요** [검증 필요] |

## 4. 제안 [의견]
1. **이음오피스 재생 시험은 그대로 의미가 있습니다.** 웹 발표기도 같은 "읽기·그리기 엔진"을 쓰므로, 목사님 다른 맥에서 이음오피스로 주일 pptx가 잘 나오면 **웹 발표기에서도 잘 나온다는 근거**가 됩니다.
2. **주안을 "예배 전용 웹 발표기"로 바꾸고**, 이음오피스 패치는 시험·비상용으로 남깁니다.
3. 첫 시제품 범위:
   - pptx 열기 → 슬라이드 그리기
   - 프로젝터 화면(전체화면) + 자막 띠
   - 노트북 발표자 화면(현재·다음 슬라이드, ← → 키)
   - 영상 재생
   - 애니메이션은 다음 단계
4. 옛 맥에서 **Chrome 138로 성능 시험**을 합니다. 버벅이면 그때 교회 맥 교체를 판단합니다.
