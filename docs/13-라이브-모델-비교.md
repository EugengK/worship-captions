# Gemini 라이브 모델 비교 — 어떤 모델로 자막을 만들까 (2026-10-28)

목사님 질문: "Gemini 3.8 Live가 3.5 Live Translate보다 싼데, 자막이 안 되나?"

## 가격 (목사님이 보내신 AI Studio 화면, 100만 토큰당)
| 모델 | 오디오 입력 | 오디오 출력 | 텍스트 출력 |
|---|---|---|---|
| gemini-3.5-live-translate-preview | $3.50 | $21.00 | – |
| gemini-3.8-live | $3.00 | $12.00 | $4.50 |
| gemini-3.5-transcribe-live | (화면에 없음 — 확인 필요) | 음성 출력 없음 | |

## 시험 (같은 47초 한국어 설교 음성, 실시간 속도)
| 모델 / 방식 | 결과 |
|---|---|
| **3.8 Live — 글자만 받기** | ✕ "TEXT 응답은 이 모델이 지원하지 않음" 오류. 반드시 음성으로 대답해야 함 |
| **3.8 Live — 통역사 지시문 + 음성 대답** | ✕ 첫 문장을 번역하다 **다음 말이 들어오자 스스로 끊김**("Dear beloved congregation, today we will meditate together"에서 멈춤), 이후 문장은 번역 안 함 |
| **3.8 Live — 끊김 방지(`NO_INTERRUPTION`)** | ✕ 첫 문장만 번역하고 **그 뒤 입력을 더 처리하지 않음**. 전체 음성으로 시도하면 연결이 끊김(keepalive timeout) |
| 3.5 Live Translate (기존) | ○ 1초마다 몇 단어씩 한국어 글자 제공. 영어 음성도 만들어 내지만 자막에는 안 씀 |
| **3.5 Transcribe Live — 기본 설정** | △ 인식은 정확하지만 글자가 **몰아서** 옴(최대 약 19초 지연) |
| **3.5 Transcribe Live — 말 끝 감지 민감도 높임** | ◎ 문장이 끝나고 **약 0.5~1초 뒤** 문장 단위로 옴 |

### 결론
- **3.8 Live는 "대화용"**이라 한 사람이 쉬지 않고 이어 말하는 설교 통역에는 이번 시험에서 동작하지 않았습니다. 가격이 싸도 지금 용도로는 쓸 수 없습니다. 나중에 설정 방법이 생기면 다시 시험할 가치는 있습니다.
- **자막용 인식은 `gemini-3.5-transcribe-live`(민감도 높임)로 바꿨습니다.** 영어 음성을 만들지 않아 버리는 비용이 없고, 이번 시험에서 인식 품질도 가장 좋았습니다.
- 3.5 Live Translate는 **나중에 성도 휴대폰 음성 통역**용으로 씁니다. 그때는 영어 음성이 필요하기 때문입니다.

## 비용 측정 (2026-10-28 추가)
- `gemini-3.5-live-translate-preview`는 Live API가 사용량을 알려 줍니다: **오디오 입력 초당 25토큰, 오디오 출력 초당 25토큰** [이번 시험에서 측정].
  - 1시간 = 입력 90,000토큰 × $3.50/100만 + 출력 90,000토큰 × $21.00/100만 ≈ **$0.32 + $1.89 = 약 $2.2/시간**
  - 이 중 약 85%가 우리가 자막에 쓰지 않는 **영어 음성 출력** 비용입니다.
- `gemini-3.5-transcribe-live`는 사용량 정보를 보내지 않았고, AI Studio 모델 목록에서도 가격을 찾지 못했습니다(모델 정보 조회 결과: 버전 `3.5-transcribe-live-08-2026`, 설명 없음).
  - 음성 출력이 없으므로 위의 큰 비용 항목은 없지만, **정확한 단가는 미확인**입니다.
  - 확인 방법: AI Studio의 사용량/결제 화면에서 이 모델의 오늘(10/28) 사용 금액을 확인합니다. 시험으로 약 5분 분량을 사용했습니다.
- 번역(`gemini-3.5-flash`)은 문장당 짧은 텍스트 요청이라 음성 비용보다 훨씬 작을 것으로 예상합니다(미측정).
