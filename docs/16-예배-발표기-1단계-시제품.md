# 예배 발표기 1단계 시제품 (2026-10-30)

> 표기: **[확인]** 클라우드에서 시험함 / **[검증 필요]** 목사님 맥에서 확인해야 함 / **[의견]** Claude의 판단

## 만든 것
- `player/`: 브라우저에서 도는 예배 발표기. 맥에 설치할 것 없음(파일은 저장소에 포함).
- 실행: `bash start-mac.sh worship`(실제 번역) / `bash start-mac.sh player-demo`(데모 자막, 비용 없음)
- 기능
  - pptx 열기(버튼 또는 끌어다 놓기)
  - 발표자 창: 현재·다음 슬라이드, 노트, 슬라이드 목록(번역 켜진 슬라이드는 초록 밑줄), 최근 자막, 자막 서버 연결 상태
  - 청중 창: 슬라이드를 화면 가득, 16:10 프로젝터에서는 남는 아래 공간과 겹쳐 자막 띠
  - 키·클리커: →/←, Space, PageDown/PageUp, Home/End, `T` 번역 켜기/끄기, `B` 화면 가림, 청중 창에서 `F` 전체 화면
  - 노트 `[번역 ON]`/`[번역 OFF]` → 엔진이 꺼진 동안 소리를 Google에 보내지 않음
  - 소리 아이콘은 프로젝터에서 숨김, "자동 재생" 음악은 그 슬라이드에서 자동 재생·넘기면 멈춤
  - pptx에 포함된 글꼴(맑은 고딕, 나눔 계열 등) 불러오기

## 이음오피스 엔진을 브라우저로 옮긴 방법
- 엔진은 원래 Electron 앱의 Node 쪽에서 돔. Node 전용 부분은 **저장·편집용**뿐이었음 → 브라우저용 대체 코드(`player/src/shims/`)로 교체 [확인]
  - `createHash`(파일 지문) → 간단한 지문, `randomUUID` → 브라우저 기능, 저장용 `fs`/`zlib` → 사용 안 함
  - `Buffer` → 공개 `buffer` 패키지
- 글자 폭 측정: 이음오피스 앱은 Node에서 글꼴 파일을 읽어 잼. 발표기는 **브라우저 캔버스로 직접 잼** → 화면에 그리는 글꼴과 같은 글꼴로 줄바꿈 계산

## 실제 주일예배 pptx(116장, 194MB) 시험 [확인: 클라우드 Chromium]
- 여는 시간 약 5~6초, 오류 없음
- 116장 모두 그려짐, 발표자↔청중 창 동기화, 청중 창 키 입력 → 발표자 창으로 전달
- 1번 슬라이드 음악 자동 재생 확인, 소리 아이콘 숨김 확인
- 번역 켜기/끄기 신호가 허브를 거쳐 엔진에 전달됨 (자동 시험 14개 + 발표기 규칙 시험 3개 통과)

## 이 파일에 대해
- 노트에 표시가 하나도 없음 → 지금은 **처음부터 끝까지 번역 켜짐**. `T` 키로 수동 전환하거나, 매주 쓰는 원본 pptx의 노트에 표시를 넣어야 자동 전환됨
- 굴림은 pptx에 포함되어 있지 않음 → 맥에서는 Apple SD Gothic Neo로 대신 그림 → **줄바꿈 위치가 PowerPoint와 다를 수 있음 [검증 필요]**

## 추가 (같은 날): 자막 언어 선택, 프로젝터 전체 화면
- 자막 언어: **기본 영어**. 발표자 화면 위쪽에서 중국어·태국어·베트남어를 더해 **최대 3개**까지 고름 → 허브 `control`의 `langs` → 엔진 번역 언어가 바뀜(언어가 늘면 번역 토큰이 조금 늘어남). 선택은 브라우저에 기억됨
- 프로젝터 창 전체 화면: 브라우저 보안상 **그 창 안에서 한 번 누르는 동작 없이는 전체 화면을 허락하지 않음** [확인: Chromium에서 노트북 창이 대신 요청하면 거절됨]
  - Chrome의 "창 관리" 권한을 허용하면 프로젝터 화면에 꽉 차게 열고 전체 화면 팝업을 요청함 [검증 필요: 클라우드 브라우저에는 이 권한이 없어 시험 못 함]
  - 안 되면 창을 **한 번 누르면** 전체 화면(안내 문구 표시)
