## 첫 실전 시험 결과 (2026-10-31, 목사님 집, 교회 MacBook Air + 아이폰 웹 마이크) [확인]
- 아이폰 Safari → Wi-Fi → 에어로 소리 전달, 한국어 인식·영어/중국어/태국어 번역, 프로젝터 자막까지 동작
- 요청: 자막 글씨가 작음 → 기본 크기 약 35% 키움, 발표자 화면 "자막 글씨 A−/A+"(−/+ 키)로 예배 중 조절 가능

## 1. 목사님이 보내 주실 것 (토요일까지 권장)
Google Drive에 주일마다 폴더 하나 (예: `주일예배/2026-11-01/`)를 만들고 넣기:
1. 완성된 **예배 pptx**
2. **예배 대본** 전체 (Word·Google 문서·txt 아무거나): 예배로 부름, 기도문, 광고, 설교 원고, 축도 등
3. 이번 주 **교독문 번호**·**성경 본문**(대본에 있으면 생략)

→ 대화창에 "이번 주 자료 올렸어" + 폴더 링크

## 2. Claude가 하는 작업
1. pptx 슬라이드를 하나씩 읽음 (글 상자 + 그림 속 글씨)
2. 대본과 슬라이드를 맞춰 **슬라이드마다** 정함:
   - **준비된 자막**(미리 번역): 예배로 부름, 교독문(NIV), 성경 구절(NIV TXT에서), 설교 제목, 기도 제목, 기도문, 축도, 영어 없는 찬양 가사
   - **실시간 번역 켬**: 설교, 광고, 대표기도(원고와 다를 수 있는 부분)
   - **끔**: 영어가 이미 있는 찬송가 이미지, 사도신경(목사님이 직접 만드심) 등
3. 이것을 **자막 파일 하나(`.json`)**에 담음. 켜기/끄기도 이 파일에 들어가므로 **PPT 노트를 고칠 필요 없음**
4. 확인용 **대조표**(슬라이드 번호 · 한국어 · 영어)를 함께 드림 → 목사님이 훑어보고 고칠 곳 알려 주기

### 찬양 가사 (2026-10-31 목사님 결정)
- 웹 검색으로 **공식 영어 가사**를 찾아 씀 (번안곡 등). 대조표에 **출처** 표기
- 공식 영어 가사가 없으면(한국 창작 찬양) Claude가 뜻을 옮겨 번역, 대조표에 **"Claude 번역"** 표시
- 번안 가사는 줄이 1:1로 맞지 않으므로 **슬라이드 단위(그 화면의 구간)**로 맞춤
- 가사 사이트가 이 환경에서 막히면 허용 목록 추가 또는 목사님이 곡 제목·가사 제공
- 화면 가사 사용 허가(CCLI 등) 가입 여부 확인 필요 [확인 안 됨]

## 3. 에어로 옮기기
- Claude가 자막 파일을 **같은 Drive 폴더**에 올림 (또는 대화창 파일로 전달)
- 예배 때 에어에서: Drive에서 pptx와 자막 파일을 내려받음 → 발표기에서 **두 파일을 함께** 고르기(또는 끌어다 놓기)
- 발표기 아래 슬라이드 목록: **파란 밑줄 = 준비된 자막**, **초록 = 실시간 번역**, 표시 없음 = 꺼짐
- 자막 파일을 만든 뒤 PPT를 고치면 번호가 어긋날 수 있음 → 발표기가 경고. 그때는 새 자막 파일 요청

## 4. 설교 원고 따라가기 (2026-10-31 구현, 실제 설교로 시험 전)
- 준비: 원고 → 문장 나누기(`hub/prepare_script.py`) → 문장마다 번역(Claude 또는 `--translate en,th`) → `설교.json`
- 예배: `SCRIPT=~/Downloads/설교.json bash start-mac.sh worship-phone` (`live_engine.py --script`)
- 들은 한국어 문장을 원고의 **지금 위치 근처**에서 찾음 (`hub/script_follow.py`):
  - **글자까지 원고 그대로** → 준비된 번역을 바로 띄움 (번역 호출 없음, 더 빠름)
  - **비슷함**(오인식·말 바꿈) → 원고 문장과 준비된 번역을 **힌트로 주고 즉석 번역**: 뜻이 같으면 준비된 번역 그대로, 숫자·부정·이름 등이 다르면 **말한 대로** 번역
  - **이미 띄운 문장** → 다시 띄우지 않음
  - **원고에 없음**(애드리브) → 즉석 번역
- 이유 [확인: 시험]: 글자 비교만으로는 "일곱 번"→"세 번", "알지 못하고"→"알고…만" 같은 **뜻 바뀜을 구별 못 함**(일치율 0.9 이상). 그래서 완전 일치만 바로 쓰고 나머지는 번역기가 확인
- 비용: 듣기(받아 적기) 비용은 같음. 번역 호출은 원고 그대로인 문장만큼 줄어듦
- **[미확인]** 힌트를 받은 Gemini가 실제로 숫자·부정 변화를 따르는지는 시험 못 함(2026-10-31 이 작업 환경의 키가 월 지출 한도 초과)
