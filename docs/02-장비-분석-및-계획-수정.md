## 2. 계획에 생기는 변화

### 2-1. 빠지는 선택지
- **PowerPoint 내장 자막** → 해당 없음. Keynote에는 실시간 자막·번역 기능이 없는 것으로 보입니다. 다만 근거는 사용자 포럼 글뿐이라 "없다고 확인"이 아니라 **"있다는 자료를 찾지 못함"**입니다. ([MacPowerUsers 포럼](https://talk.macpowerusers.com/t/keynote-accessibility-subtitles/24893))
- **OBS** → 생방송을 하지 않으므로 뺍니다. 운영이 단순해져서 오히려 좋습니다.
- **로컬 AI(맥 안에서 직접 음성인식)** → **[의견] 이 맥으로는 사실상 어렵습니다.** 듀얼코어 인텔 CPU에 AI용 그래픽 성능도 없어서, Whisper 같은 모델을 실시간으로 돌리면 지연이 너무 클 것으로 봅니다.
  → **클라우드 엔진(Soniox, OpenAI 등)을 쓰는 것이 사실상 필수**이고, 그러려면 **예배당 인터넷이 필수**입니다.
  → 맥은 "소리 보내기 + 자막 화면 띄우기"만 맡으면 되므로 오래된 맥으로도 충분할 것으로 봅니다 [의견].

### 2-2. 오디오 입력: USB 오디오 인터페이스가 필요합니다
- **[의견]** MacBook Air의 이어폰 단자는 믹서의 라인 신호를 받는 입력 단자로 쓰기 어렵고, 지금은 이미 **출력**(맥 → 믹서 COMP)으로 쓰고 있습니다.
- 그래서 **작은 USB 오디오 인터페이스**(USB-A 연결, 드라이버 없이 맥에서 인식되는 제품)를 하나 사는 것을 권합니다. 예: RCA 입력이 있는 Behringer UCA202/UCA222 계열. 구매 전에 **Big Sur 호환 여부**를 판매처에서 확인하세요.

**연결 방법 두 가지**

| 방법 | 연결 | 장점 | 단점 |
|---|---|---|---|
| **A. RECORD OUT** (가장 간단) | EPM8 `RECORD OUT`(RCA) → RCA 케이블 → USB 인터페이스 → 맥 | 설정 변경 없이 바로 연결 | 메인 믹스 전체가 들어감 → **찬양 반주·음원도 인식**하려고 해서 엉뚱한 자막이 뜰 수 있음 |
| **B. AUX2 OUT** (권장) | EPM8 `AUX2 OUT`(6.35mm 잭) → 6.35mm 잭↔RCA 케이블 → USB 인터페이스 → 맥 | 채널별 AUX2 노브로 **말하는 마이크(LEC, RADIO 1·2)만** 보낼 수 있음. iPod·CD·COMP는 0으로 | AUX2를 이미 모니터 스피커 등에 쓰고 있다면 사용할 수 없음 (확인 필요) |

- B를 쓸 경우, AUX2를 **POST**로 두는 것을 권합니다 [의견]. 그러면 마이크 페이더를 내렸을 때 자막 쪽으로도 소리가 가지 않으므로, 실제로 회중에게 들리는 말만 자막이 됩니다.
- ⚠️ **주의:** USB 인터페이스를 꽂으면 맥의 **소리 출력**이 USB 쪽으로 바뀔 수 있습니다. 그러면 COMP 채널로 나가던 영상·음원 소리가 끊깁니다. 시스템 환경설정 → 사운드에서 **출력은 "내장 출력/헤드폰", 입력은 "USB 인터페이스"**로 고정해야 합니다.

### 2-3. 화면: Keynote + 하단 자막
프로젝터가 **16:10(1920×1200)**이라는 점이 오히려 기회입니다.

**[의견]** Keynote 슬라이드가 16:9(1920×1080)로 만들어져 있다면, 16:10 화면에서는 이미 위아래에 검은 여백(합쳐서 약 120px)이 생기고 있을 것입니다. 이 여백을 자막 자리로 쓸 수 있습니다.

검토할 방식 (현장 테스트로 결정):

| 방식 | 내용 | 확인할 점 |
|---|---|---|
| **① 투명 자막 바를 Keynote 위에 겹치기** | Keynote는 지금처럼 전체 화면으로 재생하고, 자막 전용 창을 프로젝터 하단에 항상 위로 띄움 | Big Sur의 전체 화면 Keynote 위에 창이 정상적으로 뜨는지 (**미검증, 가장 큰 기술 위험**) |
| **② Keynote "창에서 재생" + 하단 자막 창** | Keynote의 `재생 > 윈도우에서` 기능 [확인: [Apple 가이드](https://support.apple.com/guide/keynote/tan72233051/mac)]으로 슬라이드를 창으로 띄워 프로젝터 위쪽에, 자막 창을 아래쪽에 배치 | 이 맥의 Keynote 버전에 해당 메뉴가 있는지, 창 테두리가 보이는지 |
| ③ 상용 앱 Subtitlo | Keynote 위에 자막을 덮어 주는 맥 앱. 일회성 $18 정도 [업체/목록 사이트 정보: [AlternativeTo](https://alternativeto.net/software/subtitlo/about)] | 번역 기능이 있는지 불분명, Big Sur 지원 여부 미확인 → 참고만 |

**권장 [의견]:** 자막 화면은 **웹페이지(HTML)**로 만들어 맥의 Safari에 띄우는 방식으로 시작하고, ①과 ② 중 현장에서 잘 되는 쪽을 택합니다. 같은 웹페이지를 나중에 성도 휴대폰용으로도 그대로 쓸 수 있습니다.
- 참고: Big Sur에서는 최신 Chrome 지원이 끝났을 가능성이 있어(확인 필요), **Safari 기준**으로 만드는 것이 안전합니다.

## 3. 수정된 전체 구조

```
[LEC·RADIO1·RADIO2 마이크] → [EPM8] ─AUX2 OUT(말소리만)→ [USB 오디오 인터페이스] → [MacBook Air]
                                  └─ MIX L/R → 앰프/스피커 (기존 그대로)                │
                                  ↑                                                      │
                     맥 이어폰 단자 → COMP 채널 (기존 그대로)                              │
                                                                                         ▼
                                                        작은 프로그램이 소리를 클라우드로 전송
                                                        (Soniox 등: 한국어 인식 + 번역)
                                                                                         │
                                                                                         ▼
                                                 자막 웹페이지 (Safari) → 프로젝터 화면 하단
                                                 (Keynote는 지금처럼 그대로 운영)
                                                 (나중에) 성도 휴대폰 QR 접속 → 언어 선택·번역 음성
```
