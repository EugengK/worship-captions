## 1. "마이크 → 맥 직결" 아이디어 검토

**결론 [의견]: 좋은 방향입니다. 다만 "블루투스" 마이크보다 "USB 수신기가 있는 무선 핀마이크"를 권합니다.**

| 항목 | 일반 블루투스 마이크/이어폰 | USB 수신기형 무선 핀마이크 (예: DJI Mic 계열) |
|---|---|---|
| 맥 연결 | 블루투스 | 수신기를 USB에 꽂음 |
| 음질 | 맥에서 블루투스 마이크를 쓰면 통화용 모드(HFP)로 바뀌어 **16kHz 저음질**이 됨 [보도: [Jeff Geerling](https://www.jeffgeerling.com/blog/2018/airpods-get-stuck-low-quality-16-khz-audio-mode-when-starting-vm), [mjtsai](https://mjtsai.com/blog/2023/12/13/why-is-bluetooth-sound-quality-bad-on-my-mac)] | 디지털 USB 오디오, 블루투스 제약 없음 |
| 안정성 | 기기마다 다름. 오래된 Big Sur 맥과의 궁합 불확실 | 별도 2.4GHz 무선. **USB class-compliant** 표기 → 보통 드라이버 없이 인식 [확인: [Lensrentals 사양](https://www.lensrentals.com/rent/dji-mic-2-wireless-microphone-2-person-system)] |
| 비고 | – | 구성품에 USB-A↔USB-C 케이블 포함 → 이 MacBook Air(USB-A 단자)에 바로 연결 가능 [확인: 같은 출처]. **Big Sur에서 실제로 인식되는지는 구매 전 확인 필요** |

**이 방식의 장점**
- 믹서 설정·AUX 배선·USB 오디오 인터페이스가 **모두 필요 없습니다.**
- 마이크가 목사님 입 가까이에 있으므로 **찬양 반주나 맥에서 트는 배경음악은 거의 들어가지 않습니다.** 인식 품질에 유리합니다.
- 맥의 소리 출력(이어폰 단자 → 믹서 COMP)은 그대로 둘 수 있습니다.

**한계 (받아들일지 결정 필요)**
- **목사님 목소리만** 번역됩니다. 대표기도, 성경 봉독, 광고를 다른 분이 하면 그분도 핀마이크를 차야 합니다. (2인용 송신기 세트가 있음)
- 목사님은 회중용 기존 마이크(강대상/무선)와 번역용 핀마이크를 **같이 착용**하게 됩니다.

## 2. 음성 번역 — 지금 실제로 가능한 것

### 2-1. 개발 없이 성도 각자의 휴대폰으로 (먼저 시험해 볼 가치가 큼)

| 방법 | 내용 | 조건·한계 |
|---|---|---|
| **AirPods 실시간 번역 (Apple)** | 성도가 AirPods를 끼고 있으면, 주변에서 들리는 말(스피커로 나오는 설교)을 자기 언어로 귀에 들려줌. **한국어는 iOS 26.1부터 지원** [보도: [MacRumors](https://www.macrumors.com/2025/09/22/ios-26-1-apple-intelligence-languages/)] | Apple Intelligence 지원 아이폰 + AirPods Pro 2/Pro 3/AirPods 4(ANC)가 필요함 [보도]. 지원 언어가 적음(베트남어·태국어는 목록에서 확인 못 함) |
| **Google 번역 앱 "이어폰 실시간 번역" (Gemini)** | 아무 이어폰으로나 70여 개 언어. 말하는 사람의 **억양·속도·음높이를 살린다**고 발표됨 [보도: [Chrome Unboxed](https://chromeunboxed.com/with-a-massive-gemini-upgrade-google-translate-can-now-turn-any-pair-of-headphones-into-a-real-time-translator/), [Google 블로그](https://blog.google/products-and-platforms/products/search/gemini-capabilities-translation-upgrades/)] | 2026년 3월 iOS 출시 및 국가 확대 보도. 다만 **보도된 국가 목록에 호주는 없음** [보도: [AlternativeTo](https://alternativeto.net/news/2026/3/google-translate-s-real-time-headphone-translation-feature-expands-to-ios-and-more-countries)] → 호주 휴대폰에서 메뉴가 보이는지 직접 확인 필요 |

**[의견]** 이 방법들은 비용이 0원이고 오늘이라도 시험해 볼 수 있습니다. 외국인 성도 한 분께 부탁해 이번 주일에 시험해 보면, **"우리가 음성 번역까지 직접 만들 필요가 있는가"**를 판단할 수 있습니다. 다만 성도 각자가 기기와 설정을 갖춰야 하고, 신학 용어집 같은 교회 맞춤 설정은 할 수 없습니다.

### 2-2. 우리가 직접 만드는 경우: OpenAI `gpt-realtime-translate`
- **하나의 연결에서 "번역 음성 + 번역 텍스트"가 함께 나옵니다.** → 텍스트는 프로젝터 자막으로, 음성은 성도 휴대폰으로 보낼 수 있습니다. **엔진 하나로 두 가지 목표를 다 처리**하는 가장 단순한 구조입니다.
- 목소리: 고정된 성우 목소리가 아니라 **원래 화자의 톤·음높이·말하는 스타일을 따라간다**고 OpenAI 가이드에 나와 있습니다. 단, 목소리를 **똑같이 복제하는 것은 아닙니다** [확인: [OpenAI 쿡북](https://developers.openai.com/cookbook/examples/voice_solutions/realtime_translation_guide)].
- 언어: 입력 70개 이상, **출력 13개**. 영어·중국어·베트남어는 포함, **태국어는 없는 것으로 보도**됨 [보도] → 태국어는 "텍스트 번역 + 음성 합성"이라는 별도 경로가 필요합니다.
- 비용: 분당 약 $0.034 보도 → 1시간에 **언어당 약 $2** [보도]. 영어 1개 언어로 주 2~3시간이면 월 $20~30 수준으로 추정합니다 [의견].
- 주의: 이 모델은 **글자 그대로의 정확성보다 자연스러움과 속도에 맞춰져 있다**는 평가가 있습니다 [보도: [MindStudio](https://www.mindstudio.ai/blog/gpt-realtime-2-vs-translate-vs-whisper-comparison)]. 설교 번역에서는 반드시 실제 설교로 품질을 확인해야 합니다.
- 비교 후보: Google도 Gemini 기반 실시간 통역 모델을 내놓은 것으로 보도되었으나, 개발자용 API의 조건은 아직 확인하지 못했습니다.

### 2-3. 음성을 성도에게 전달하는 방법 [의견]
- 성도가 휴대폰으로 **QR 코드 → 웹페이지 → 언어 선택 → 이어폰으로 듣기**. 앱 설치는 필요 없습니다.
- 이를 위해서는 맥에서 나온 번역 음성을 여러 휴대폰에 나눠 줄 **작은 중계 서버**(클라우드)가 필요합니다. 이 부분이 개발에서 **가장 손이 많이 가는 부분**이라 2단계로 미룹니다.

## 3. 추천: 가장 단순하고 빠른 순서 [의견]

```
[목사님 무선 핀마이크] ──USB 수신기──> [MacBook Air]
                                         │  (작은 웹앱: 마이크 소리 → OpenAI 실시간 번역)
                                         ├─> 번역 텍스트 → 프로젝터 하단 자막 (Keynote 위)
                                         └─> 번역 음성 → (2단계) 성도 휴대폰 이어폰
[기존 강대상/무선 마이크] → EPM8 → 스피커   (기존 그대로, 손대지 않음)
[맥 이어폰 단자] → EPM8 COMP                (기존 그대로)
```

| 단계 | 할 일 | 비용 | 목적 |
|---|---|---|---|
| **1** (이번 주) | 외국인 성도 1명과 **AirPods 번역 / Google 번역 이어폰 모드**를 예배 중에 시험 | 0원 | 기준선 확인. 이것으로 충분하면 음성 쪽 개발은 생략 |
| **1** (이번 주) | Claude가 **화면 테스트 페이지**를 만들고 → Keynote 위 하단 자막 배치 확인 | 0원 | 가장 큰 기술 위험 확인 |
| **2** | USB 수신기형 무선 핀마이크 구입 (Big Sur 호환 확인 후) | 장비 1회 | 소리 입력 단순화 |
| **3** | MVP: 핀마이크 → OpenAI 실시간 번역(영어) → **프로젝터 자막** + 맥에서 번역 음성 시험 청취 | 사용량 과금 | 수요예배에서 시험 |
| **4** | 성도 휴대폰 QR 음성 듣기 (중계 서버) + 언어 추가 + 신학 용어집 | 소액 서버비 | 확장 |

**목회적 고려 [의견]:** 번역 음성이 목사님 목소리의 톤을 따라 하기 때문에, 회중이 그것을 "목사님이 직접 하신 말"로 받아들일 수 있습니다. 화면과 음성 안내에 **"AI 자동 통역입니다"**라는 고지를 꼭 넣기를 권합니다.
