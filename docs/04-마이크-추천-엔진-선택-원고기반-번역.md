## 0. 확정된 요구사항
- **최우선: 태국어.** 한국어도 영어도 어려운 태국인 자매님이 설교를 모국어로 이해하는 것이 1차 목표.
- 화면 병기: 예) **위 영어 / 아래 태국어**. 언어는 예배마다 선택 가능해야 함(중국어 등).
- 성도 휴대폰은 **아이폰·삼성 모두** 지원해야 함 → AirPods 방식 제외, **앱 설치 없는 웹페이지** 방식.
- 기독교·설교 용어집 반영. **설교 원고를 미리 받아 번역 품질을 높이는 방식** 도입.
- OpenAI API 계정 생성 가능.

**[의견] 추천 조합**
- **화면 자막(텍스트):** Soniox(또는 Google)로 한국어를 **인식**하고, 번역은 **원고 + 용어집 + LLM**으로 합니다 (아래 3장).
- **휴대폰 음성:** Google `gemini-3.5-live-translate`. **태국어 지원이 확인되면** 2단계에서 붙입니다.
- 최종 결정은 **실제 설교 녹음 1편으로 비교 시험**한 뒤에 내리겠습니다. 이때 태국어 번역 품질은 자매님께 직접 확인받는 것이 가장 정확합니다.

## 3. 원고 기반 번역 설계 (목사님 아이디어 구체화) [의견]

목사님 생각이 맞다고 봅니다. 연극이나 오페라의 **자막(surtitle) 운영**이 바로 이 방식입니다. 미리 번역해 둔 문장을 공연 진행에 맞춰 띄웁니다. 여기에 AI가 "지금 원고의 어디를 말하고 있는지"를 자동으로 따라가게 하는 구조입니다.

### 3-1. 예배 전 (금·토요일)
```
설교 원고(한국어) ─┐
교회 용어집 ───────┼─> LLM이 문장 단위로 번역 (태국어·영어 등)
성경 본문 ─────────┘        │
                            ▼
              "문장 번호 | 한국어 | English | ไทย" 표 생성
                            ▼
              (선택) 목사님이 영어를 검토하고, 가능하면 태국어 확인
```
- 용어집 예시: 하나님 → God / พระเจ้า, 언약 → covenant, 칭의 → justification, 하이델베르크 요리문답 → Heidelberg Catechism, 창세기 → Genesis.
  - 태국어 기독교 용어는 **태국 교회에서 실제로 쓰는 표현**을 따라야 합니다. 초안은 제가 만들 수 있지만, **태국어 용어의 정확성은 제가 보증할 수 없으니** 자매님이나 태국 교회 자료로 확인해야 합니다.
- 성경 인용은 그 언어의 **공인 성경 번역본** 문장을 쓰는 것이 이상적입니다. 저작권을 확인해야 합니다.

### 3-2. 예배 중
```
핀마이크 → 맥 → 실시간 한국어 인식(Soniox 등)
                    │
                    ▼
        "원고 추적기": 인식된 문장이 원고의 몇 번 문장과 비슷한가?
           ├─ 일치 (원고대로 설교) → 미리 번역해 둔 문장을 즉시 표시 ✅ 정확·빠름
           └─ 불일치 (애드리브) → 그 문장만 실시간 번역
                                  (원고 앞뒤 문맥 + 용어집을 함께 넘겨 자연스럽게)
```
- 장점: 원고대로 설교하는 부분은 **사람이 검토한 번역**이 나가므로 오역이 거의 없습니다. 애드리브도 원고 문맥을 알고 번역하므로 품질이 좋아집니다.
- 위험: 추적기가 원고 위치를 **잘못 짚을** 수 있습니다. 그래서 운영자가 **← → 키로 바로잡는 기능**을 반드시 넣겠습니다.
- 원고가 없는 순서(기도, 광고, 축도 등)는 실시간 번역만으로 처리합니다.

### 3-3. 기술 없이 당장 가능한 0단계 (이번 주일부터)
**AI 실시간 인식 없이도** 자매님께 바로 도움을 드릴 수 있습니다.
1. 목사님이 설교 원고를 주시면, 제가 **문장별 태국어(+영어) 번역 자막 파일**과 **넘김용 웹페이지**를 만듭니다.
2. 예배 때 맥 옆의 봉사자가 설교를 들으며 **→ 키로 문장을 넘깁니다** (Keynote 넘기듯이).
3. 결과물은 나중에 자동 추적 시스템에도 그대로 사용됩니다. 버리는 작업이 없습니다.
- 필요한 것: 원고, 넘길 봉사자 1명, 화면 배치 확인(Keynote 위 하단 자막).
- 비용: 0원 (번역은 이 대화에서 제가 처리)

1. 이번 주일(또는 다음 수요예배) 설교 원고를 미리 주실 수 있나요? 어떤 형식인가요? (한글/Word/텍스트)
