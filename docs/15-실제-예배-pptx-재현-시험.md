## 재현 시험
- 방법: 대표 슬라이드 22장을 이음오피스 `pptx-engine`으로 읽음 → `pptx-render`로 1920폭 그리기 정보 생성 → 이음오피스 그리기 부품 `SlideThumb`(react-konva)로 브라우저(Chromium)에 그림
- 결과: **오류 없음.** 슬라이드 1장 계산 0~6ms
- 배경 사진, 악보·가사 이미지, 제목 상자, 본문 글자 배치가 원본 구성대로 나옴 [화면으로 확인]

### 차이가 보인 점
1. **줄바꿈 위치가 다른 곳이 있음.** 예: "호바트한인교 / 회", "세상의 헛된 신을 버리 / 고", 사도신경의 "믿습니 / 다"
   - 원인 추정: 시험 환경에 굴림·맑은 고딕이 없어 **다른 글꼴로 대신 그렸기 때문**. 이 시험에서는 pptx 안에 포함된 글꼴도 아직 불러오지 않았음
   - 대책: 발표기에서 ① pptx 포함 글꼴을 불러오기(이음오피스에 해당 기능 있음) ② 맥에 설치된 글꼴로 글자 폭 계산 → 맥에서 다시 확인
2. **소리 아이콘이 보임**(첫·마지막 슬라이드): 발표 화면에서는 아이콘을 숨기고 mp3를 재생해야 함 → 발표기 1단계에 포함
